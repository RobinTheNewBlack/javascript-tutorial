# JavaScript Fundamentals

# ส่วนที่ 5: การวนซ้ำ (Loops)

## Loops คืออะไร?

Loop คือโครงสร้างที่ใช้ทำงานซ้ำๆ หลายรอบโดยไม่ต้องเขียนโค้ดซ้ำ เช่น การวนผ่านข้อมูลใน Array หรือทำงานจนกว่าเงื่อนไขจะเป็นเท็จ

---

## 1. `for` Loop

Loop พื้นฐานที่ใช้บ่อยที่สุด เหมาะเมื่อรู้จำนวนรอบที่แน่นอน

รูปแบบ: `for (เริ่มต้น; เงื่อนไข; อัปเดต) { ... }`

```js
for (let i = 0; i < 5; i++) {
    console.log(`รอบที่ ${i + 1}`);
}
// รอบที่ 1
// รอบที่ 2
// รอบที่ 3
// รอบที่ 4
// รอบที่ 5
```

### วนย้อนหลัง

```js
for (let i = 5; i >= 1; i--) {
    console.log(i);
}
// 5, 4, 3, 2, 1
```

### วนผ่าน Array

```js
const fruits = ["แอปเปิ้ล", "กล้วย", "ส้ม"];

for (let i = 0; i < fruits.length; i++) {
    console.log(`${i}: ${fruits[i]}`);
}
// 0: แอปเปิ้ล
// 1: กล้วย
// 2: ส้ม
```

---

## 2. `while` Loop

วนซ้ำตราบเท่าที่เงื่อนไขยังเป็น `true` เหมาะเมื่อไม่รู้จำนวนรอบล่วงหน้า แต่รู้ว่าต้องหยุดเมื่อเงื่อไนขอะไรเกิดขึ้น

```js
let count = 0;

while (count < 3) {
    console.log(`นับ: ${count}`);
    count++;
}
// นับ: 0
// นับ: 1
// นับ: 2
```

### ตัวอย่างการใช้งานจริง

```js
let userInput = "";

while (userInput !== "หยุด") {
    userInput = prompt("พิมพ์คำสั่ง (พิมพ์ 'หยุด' เพื่อออก):");
}
console.log("จบการทำงาน");
```

> **ระวัง:** ถ้าเงื่อนไขไม่มีวันเป็น `false` จะเกิด **Infinite Loop** ทำให้โปรแกรมค้าง

---

## 3. `do...while` Loop

คล้ายกับ `while` แต่จะทำงานอย่างน้อย **1 รอบเสมอ** แม้เงื่อนไขจะเป็น `false` ตั้งแต่แรก

```js
let i = 0;

do {
    console.log(`ทำงานรอบที่ ${i + 1}`);
    i++;
} while (i < 3);
// ทำงานรอบที่ 1
// ทำงานรอบที่ 2
// ทำงานรอบที่ 3
```

### เปรียบเทียบกับ `while`

```js
let x = 10;

// while — ไม่ทำงานเลยเพราะเงื่อนไขเป็น false ตั้งแต่แรก
while (x < 5) {
    console.log("while:", x);
}

// do...while — ทำงาน 1 รอบเสมอ แม้เงื่อนไขจะเป็น false
do {
    console.log("do...while:", x); // "do...while: 10"
} while (x < 5);
```

---

## 4. `for...of` Loop

ใช้วนผ่านค่าใน **Iterable** เช่น Array, String, Map, Set เขียนง่ายและอ่านชัดกว่า `for` ทั่วไป

```js
const fruits = ["แอปเปิ้ล", "กล้วย", "ส้ม"];

for (const fruit of fruits) {
    console.log(fruit);
}
// แอปเปิ้ล
// กล้วย
// ส้ม
```

### วนผ่าน String

```js
const word = "สวัสดี";

for (const char of word) {
    console.log(char);
}
// ส, ว, ั, ส, ด, ี
```

### วนพร้อม index โดยใช้ `entries()`

```js
const colors = ["แดง", "เขียว", "น้ำเงิน"];

for (const [index, color] of colors.entries()) {
    console.log(`${index}: ${color}`);
}
// 0: แดง
// 1: เขียว
// 2: น้ำเงิน
```

---

## 5. `for...in` Loop

ใช้วนผ่าน **key** ของ Object เหมาะสำหรับการดู property ทั้งหมดของ object

```js
const person = {
    name: "สมชาย",
    age: 30,
    city: "กรุงเทพ",
};

for (const key in person) {
    console.log(`${key}: ${person[key]}`);
}
// name: สมชาย
// age: 30
// city: กรุงเทพ
```

> **หมายเหตุ:** ไม่ควรใช้ `for...in` กับ Array เพราะอาจวนผ่าน property ที่ไม่ต้องการด้วย ให้ใช้ `for...of` แทน

## 6. Array Methods แทน Loop (Functional Style)

JavaScript มี built-in method ที่ช่วยวน Array ได้กระชับและอ่านง่ายกว่า loop ทั่วไป

### `forEach` — วนทำงานกับทุก element

```js
const numbers = [1, 2, 3, 4, 5];

numbers.forEach((num) => {
    console.log(num * 2);
});
// 2, 4, 6, 8, 10
```

### `map` — วนและสร้าง Array ใหม่

```js
const prices = [100, 200, 300];
const discounted = prices.map((price) => price * 0.9);

console.log(discounted); // [90, 180, 270]
```

### `filter` — กรองเฉพาะ element ที่ผ่านเงื่อนไข

```js
const scores = [45, 72, 88, 55, 91];
const passed = scores.filter((score) => score >= 60);

console.log(passed); // [72, 88, 91]
```

### `reduce` — รวม Array เป็นค่าเดียว

```js
const cart = [120, 350, 80, 200];
const total = cart.reduce((sum, price) => sum + price, 0);

console.log(total); // 750
```

### `find` — หา element แรกที่ผ่านเงื่อนไข

```js
const users = [
    { id: 1, name: "สมชาย" },
    { id: 2, name: "สมหญิง" },
    { id: 3, name: "สมศรี" },
];

const user = users.find((u) => u.id === 2);
console.log(user); // { id: 2, name: "สมหญิง" }
```

### `some` และ `every` — ตรวจสอบเงื่อนไข

```js
const ages = [15, 22, 18, 30];

console.log(ages.some((age) => age >= 18)); // true — มีอย่างน้อยหนึ่งคนที่อายุ >= 18
console.log(ages.every((age) => age >= 18)); // false — ไม่ใช่ทุกคนที่อายุ >= 18
```

## 7. `break` และ `continue`

### `break` — หยุด loop ทันที

```js
for (let i = 0; i < 10; i++) {
    if (i === 5) break; // หยุดเมื่อถึง 5
    console.log(i);
}
// 0, 1, 2, 3, 4
```

### `continue` — ข้ามรอบนี้ไปรอบถัดไป

```js
for (let i = 0; i < 6; i++) {
    if (i % 2 === 0) continue; // ข้ามเลขคู่
    console.log(i);
}
// 1, 3, 5
```

### `break` ใน Nested Loop ด้วย Label

```js
outer: for (let i = 0; i < 3; i++) {
    for (let j = 0; j < 3; j++) {
        if (i === 1 && j === 1) break outer; // หยุด loop นอกสุด
        console.log(`i=${i}, j=${j}`);
    }
}
// i=0, j=0
// i=0, j=1
// i=0, j=2
// i=1, j=0
```

## 8. เปรียบเทียบ `for`, `forEach` และ `map` เชิงลึก

### `for` Loop (The Manual Way)

เป็นวิธีดั้งเดิมที่สุดแบบ **Imperative** (สั่งทีละขั้นตอน) คุณต้องกำหนดจุดเริ่ม จุดจบ และการเพิ่มค่าเอง

**จุดเด่น:** ยืดหยุ่นที่สุด สามารถใช้ `break` (หยุดกลางคัน) หรือ `continue` (ข้ามรอบ) ได้

**เหมาะสำหรับ:** งานที่ต้องการการควบคุมสูง หรือต้องการประสิทธิภาพสูงสุด (Performance) ในลูปที่ใหญ่มากๆ

```js
const numbers = [1, 2, 3];
for (let i = 0; i < numbers.length; i++) {
  if (numbers[i] === 2) break; // หยุดเมื่อเจอ 2
  console.log(numbers[i]);
}
```

### `forEach` (The Action Taker)

เป็น Method ของ Array ที่ใช้เพื่อ "ทำบางอย่างกับข้อมูลทุกตัว" โดยตรง

**จุดเด่น:** เขียนสั้นกว่า `for` อ่านง่ายขึ้น

**สิ่งที่ต้องระวัง:** มันไม่คืนค่าอะไรกลับมา (Return `undefined`) และไม่สามารถ `break` ได้ (ต้องรันจนจบทุกตัว)

**เหมาะสำหรับ:** การวนลูปเพื่อเอาข้อมูลไปทำอย่างอื่น เช่น บันทึกลง Database, แสดงผลใน Console, หรือแก้ไขค่าตัวแปรภายนอกลูป

```js
const numbers = [1, 2, 3];
numbers.forEach((num) => {
  console.log(num * 2); // แค่แสดงผลออกมา
});
```

### `map` (The Transformer)

เป็นพระเอกของ JavaScript สมัยใหม่ (โดยเฉพาะใน React) ใช้สำหรับ "แปลงร่างข้อมูล"

**จุดเด่น:** มันจะสร้าง Array ใหม่ขึ้นมาเสมอ โดยมีขนาดเท่าเดิม แต่ข้อมูลข้างในถูกเปลี่ยนตามที่เราสั่ง

**หลักการ:** ไม่แก้ไข Array ต้นฉบับ (Immutability) ซึ่งเป็นนิสัยที่ดีในการเขียนโปรแกรม

**เหมาะสำหรับ:** การสร้าง List ใหม่จากข้อมูลเดิม เช่น แปลงตัวเลขเป็น HTML หรือแปลงราคาสินค้าเป็นหน่วยเงินอื่น

```js
const numbers = [1, 2, 3];
const doubled = numbers.map((num) => num * 2);

console.log(doubled); // [2, 4, 6] (ได้ Array ใหม่มาใช้งานต่อ)
```

### ตารางเปรียบเทียบ

| คุณสมบัติ              | `for`             | `forEach`         | `map`              |
| :--------------------- | :---------------- | :---------------- | :----------------- |
| คืนค่ากลับมาไหม?       | ไม่ (ต้องเก็บเอง) | ไม่ (`undefined`) | คืนเป็น Array ใหม่ |
| หยุดลูปกลางคัน?        | ทำได้ (`break`)   | ทำไม่ได้          | ทำไม่ได้           |
| แก้ไขตัวแปรต้นฉบับ?    | แล้วแต่เขียน      | แล้วแต่เขียน      | ไม่ทำ (สร้างใหม่)  |
| ความเร็ว (Performance) | เร็วที่สุด        | ปานกลาง           | ปานกลาง            |
| ความนิยมในปัจจุบัน     | งานเฉพาะทาง       | งานทั่วไป          | สูงมาก (Modern JS) |

> **คำแนะนำ:**
> - ถ้าต้องการ **สร้าง Array ใหม่** จากของเดิม → ใช้ `.map()`
> - ถ้าแค่ต้องการ **รันคำสั่ง** (เช่น `console.log`) ให้ข้อมูลผ่านตาไปเฉยๆ → ใช้ `.forEach()`
> - ถ้าต้อง **หยุดลูป** หรือลูปมีความซับซ้อนมากๆ → ใช้ `for`

## 9. Async Loops — วนซ้ำกับงาน Asynchronous

เมื่อต้องวนลูปกับงาน Async (เช่น เรียก API, อ่านไฟล์) วิธีที่เลือกใช้จะส่งผลต่อลำดับและความเร็วอย่างมาก

### `for...of` + `await` (แบบใจเย็น)

เปรียบเหมือน: คุณทำกาแฟทีละแก้วด้วยตัวคนเดียว — ชงแก้วที่ 1 เสร็จ → เสิร์ฟ → แล้วค่อยเริ่มชงแก้วที่ 2 → ทำแบบนี้ไปจนครบ 5 แก้ว

**ความรู้สึก:** ช้าแต่ชัวร์ ลำดับเป๊ะมาก ไม่สับสน

```js
// โค้ดจะหยุดรอ "await" ในทุกๆ รอบ
for (const order of orders) {
    await makeCoffee(order); // รอจนแก้วนี้เสร็จ ถึงจะไปรอบถัดไป
    console.log("เสิร์ฟแล้ว!");
}
console.log("ทำครบทุกแก้วแล้ว"); // บรรทัดนี้จะทำงาน "หลังสุด" จริงๆ
```

### `forEach` + `async` (แบบชุลมุน)

เปรียบเหมือน: คุณตะโกนสั่งลูกน้อง 5 คนพร้อมกันว่า "ไปทำกาแฟมา!" แล้วคุณก็เดินหนีไปทันที โดยไม่รอให้ใครทำเสร็จ

**ความรู้สึก:** อันตราย ถ้าต้องรีบเอากาแฟไปส่งลูกค้าพร้อมกัน คุณจะไม่มีทางรู้เลยว่าของครบหรือยัง

```js
// ห้ามใช้แบบนี้ถ้าต้องการรอผลลัพธ์!
orders.forEach(async (order) => {
    await makeCoffee(order);
    console.log("เสิร์ฟแล้ว!");
});
console.log("ฉันไปพักละนะ!"); // บรรทัดนี้จะเด้งขึ้นมาก่อนเพื่อน ทั้งที่กาแฟยังไม่เสร็จสักแก้ว
```

### `map` + `Promise.all` (แบบมือโปร)

เปรียบเหมือน: คุณสั่งลูกน้อง 5 คนพร้อมกัน แต่คุณยืนกอดอกรออยู่ที่หน้าเคาน์เตอร์ และบอกว่า "ถ้าใครทำเสร็จแล้วให้วางไว้ตรงนี้ เดี๋ยวจะเอาไปส่งพร้อมกันทีเดียว"

**ความรู้สึก:** เร็วที่สุด เพราะไม่ต้องรอทีละแก้ว แต่ยังควบคุมผลลัพธ์ได้ครบถ้วน

```js
// สร้าง "รายการสัญญา (Promises)" ขึ้นมาว่าทุกคนกำลังทำอยู่
const coffeePromises = orders.map(async (order) => {
    return await makeCoffee(order);
});

// "Promise.all" คือการบอกว่า "รอให้ทุกใบสั่งทำเสร็จทั้งหมดก่อนนะ"
const allCoffees = await Promise.all(coffeePromises);
console.log("เอากาแฟทุกแก้วไปส่งลูกค้าพร้อมกัน!");
```

### สรุป Async Loops

| สถานการณ์                                          | ใช้                          |
| -------------------------------------------------- | ---------------------------- |
| ต้องรอลำดับที่ 1 เสร็จก่อนถึงจะทำลำดับที่ 2 ได้  | `for...of` + `await`         |
| อยากได้ความเร็ว และงานแต่ละชิ้นไม่เกี่ยวข้องกัน  | `.map()` + `Promise.all()`   |
| งาน Async ทุกกรณี                                  | **หลีกเลี่ยง `.forEach()`** |

## สรุปการเลือกใช้งาน

| สถานการณ์                                 | ใช้                       |
| ----------------------------------------- | ------------------------- |
| รู้จำนวนรอบแน่นอน                         | `for`                     |
| ไม่รู้จำนวนรอบ วนจนกว่าเงื่อนไขจะเป็นเท็จ | `while`                   |
| ต้องทำงานอย่างน้อย 1 รอบ                  | `do...while`              |
| วนผ่านค่าใน Array หรือ Iterable           | `for...of`                |
| วนผ่าน key ของ Object                     | `for...in`                |
| แปลง / กรอง / รวม Array                   | `map`, `filter`, `reduce` |
| วนทำงานกับ Array โดยไม่ต้องการค่าคืน      | `forEach`                 |
